# nicescarfs-reels

nicescarfs.com Instagram Reels işleyicisi. GitHub Actions yarım saatte bir `https://nicescarfs.com/ig/reels` listesini okur,
her videoya giriş ve kapanış kartı, hafif yakınlaştırma, renk düzeltmesi ve marka etiketi ekler, `reels` sürümüne yükler.
Site işlenmiş videoyu buradan kendisi çeker. Bu depoda anahtar ya da gizli bilgi yoktur.

Elle çalıştırma: Actions › reels › Run workflow.
